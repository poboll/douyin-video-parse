# 关键事实速查

分析过程中确认过的事实，按主题归档。**这些都是实测结论，不是推测。**

---

## 端点行为

| 事实 | 说明 |
|---|---|
| `api-play dash` 从 Mac 裸 curl 即返 302 | 带 Aweme UA，**不需要 cookie** |
| 跳转目标是**新签名**的 CDN 地址 | `l=20261021170929` 是当下时间，不是缓存旧链 |
| `er=0` = 无水印干净链 | |
| `lr=aweme_search_suffix` = 带抖音号水印 | 水印烧录在画面像素里 |
| `biz_sign` 绑定具体 video_id | 换 id 直接 404，**不可伪造** |
| `ratio` 可任选 | 服务端按该视频实际最高档回落 |
| iesdouyin 端点支持选档且无水印 | 普通浏览器 UA，无签名 |
| iesdouyin 的 1080p 比 App dash 默认档高 | 竖屏实测 `br=2577` vs `br=765` |
| `ch` / `cr` / `lr` 参数改后内容不变 | 签名 `l=` **不覆盖**这些参数 |
| cookie 无用 | CDN 直链自带签名（`l` / `x-expires`），API 层另有设备签名 |

## 加密相关（最终定案）

| 事实 | 说明 |
|---|---|
| **视频根本没加密** | mdat 是明文 HEVC，NAL 链 `[32,33,34,39,19]` 完整可解析 |
| `ffprobe` 直接读通 `.mdl` | `hevc 2560x1440, duration 4181.35s` |
| 14 个 AES hook 零调用 | **是正确结果**，不是失败——没有东西要解密 |
| `encryptVersion:0` | App 自己的下载任务配置里就写着未加密 |
| 熵 8.0 **不是**加密证据 | 压缩视频熵本来就是 8.0，该判据无效 |
| 四个端点对目标视频全 404 | 服务端按视频 ID 封锁明文路，但**根因未完全定案** |

## 缓存行为

| 事实 | 说明 |
|---|---|
| `.mdl` = 裸 MP4 | `ftyp` 开头，ffprobe 可读 |
| `.mdlnodeconf` = `ttmd` 索引 | 只有区间表 + fkey，**无 URL** |
| `fkey` 是 md5 缓存 key | **不是密钥** |
| 音视频分轨存储 | 两个独立 `.mdl` |
| 缓存文件预分配稀疏 | 790MB 文件覆盖率可能只有 2.9% |
| 离线下载只给 576p / 684kbps | `AWEOfflineCenter` 自己选了最低档 |
| 播放缓存上得去 1440p / 4K | 文件名带 gear 名 |
| **播放器只预下载音频轨，视频走流式不落盘** | 这是必须走注入抓流的直接原因 |
| 播放按网络自适应选档 | 要最高画质必须**手动切档** |

## App 行为

| 事实 | 说明 |
|---|---|
| **断点续播** | 每轮播放从上次观看位置恢复（实测 6.62s / 5.785s），片头从不被解码 |
| 从「我的」标签页进不触发预加载 | 不会把完整直链写盘，盯梢器抓不到东西 |
| 手动切档才会写带 `biz_sign` 的请求 | 进预加载存储 |
| 清晰度菜单里可能没有 4K 选项 | 该片最高就是 2K |
| 播放时锁屏会暂停，数据断 | |
| 音频走 `avcodec_receive_frame`（FFmpeg 解码） | 不走 AudioQueue / AudioUnit / AVAudioEngine |
| 音频 3 倍速入队不影响内容完整性 | 解码点抓取，无需倍速还原 |

## 安全提醒

| 事实 | 说明 |
|---|---|
| WebDAV `192.168.1.70:11111` **免认证暴露整个 iPad 文件系统** | 不只是 App 容器——相册、微信数据库全在里面 |
| 同一 WiFi 下任何人可读 | **事办完必须关掉** |
| TrollStore 注入会改 App 二进制 | 有登录风控风险，`dumper.m` 注释里明确写了 |
| frida-server.ipa 有后台挂起死穴 | iOS 会挂起它，必须保持前台，与"要播放抖音精选"冲突 |
| frida-gadget.dylib 是正解 | 端口 27042，无界面 |
