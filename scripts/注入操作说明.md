# 《女主》第二集 DRM dump —— 操作说明（最终版）

## 背景（30 秒版）

付费剧集被抖音服务端按视频 ID 封锁：所有明文下载端点 404，App 直链是加密 mdat。
解密类已定位：`MediaDecrypter`（AwemeJXCore，AES）。
三条注入路线按顺滑度排序，**推荐路线 1**。

---

## 路线 1（最顺，零安装）：ep2dump.dylib 直接注入

你的巨魔注入器现成，不用装任何东西。

1. 用注入器把 `ep2dump.dylib` 注入**抖音精选**
2. 先建 RECON 文件（只记日志不落盘，防刷爆磁盘）：
   Filza 打开 `抖音精选/Documents/ep2dump/` 目录（没有就新建），丢一个空文件叫 `RECON`
3. 打开抖音精选，播放《女主》第二集，**清晰度选 4K，播 30 秒**
4. 把 `Documents/ep2dump/log.txt` 发我（Filza 里长按分享，或 WebDAV 恢复后拖走）
   - 日志里会有每次解密调用的：方法名、参数长度、密钥前 96 字节
5. 我确认 hook 命中后：删掉 RECON 文件，重播完整一集（70 分钟）
   → dump 全量数据到 `Documents/ep2dump/`（上限 5GB）→ 发我 → 我解密合成

**注意**：RECON 文件删掉才会落盘数据；密钥候选（16/24/32 字节）单独存在 `keys/` 子目录。

## 路线 2（frida，我可实时迭代）：frida-gadget 注入

愿意多注入一个 dylib 的话选这个——我能在 Mac 上实时看每次调用、随时改 hook，
命中不对立刻换，不用你反复重注入。

1. 把 `frida-gadget.dylib`（62MB）也用注入器注入**抖音精选**（和路线 1 的插件可同时注入）
2. iPad 连 WiFi（和 Mac 同一局域网），设置里看 iPad 的 IP（之前 WebDAV 是 192.168.1.70）
3. 打开抖音精选（gadget 会自动监听 27042 端口，无界面）
4. Mac 终端：
   ```bash
   ${PYTHON:-python3} \
     ./frida_run.py remote 192.168.1.70
   ```
5. 播放《女主》第二集 30 秒（4K），终端输出发我

## 路线 3（备胎，不推荐）：frida_server.ipa

TrollStore 装 `frida_server.ipa` 能用，但 iOS 会把它挂起，
必须保持它在前台——和「要播放抖音精选」冲突，基本不可用。留着以防万一。

---

## 通用注意事项

- 播放时**别锁屏**（锁屏暂停，数据断）
- 别拖进度条、别切清晰度，让解码器顺序读完整文件
- App 崩了/没反应 → 把 log.txt 或终端输出发我，我判断是 hook 点问题还是被检测
