## 一、正则 / 文本解析

### 1. mmkv URL 提取 0 匹配

**症状**：从 mmkv 抓 URL，正则跑出来一条没有。

**根因**：mmkv 里 URL 是 JSON 转义形式 `https:\/\/...`，而正则写的是 `https:[^"\\\s]+`——`https:` 后紧跟的就是反斜杠，被字符类排除了，所以 0 匹配。

**修法**：

```python
# 允许反斜杠进入，再统一还原
for m in re.finditer(r'https:[^"\s\x00,]+', text):
    u = m.group(0).replace("\\/", "/").replace("\\u0026", "&").rstrip('\\"')
```

### 2. 新鲜度 token 匹配不上

**症状**：`l=(20\d{12})` 抓不到新链接。

**根因**：新格式是 **14 位时间戳 + hex**（`l=202610211652412E72...`），长度超过 12 位；旧格式才是纯 14 位数字。

**修法**：用 `l=2026` 或 `l=(20\d{12,})`。

### 3. WebDAV PROPFIND 把目录当文件

**症状**：shell 爬虫递归时卡死 / 报错。

**根因**：PROPFIND 对**目录也返回 `getcontentlength`**，只看长度判断不了是不是文件。

**修法**：必须看 `resourcetype/<D:collection/>`。

### 4. PROPFIND 正则要求元素相邻

**症状**：解析出的条目缺字段。

**根因**：`<D:getcontentlength>` 和 `<D:href>` 之间隔着 `resourcetype` / `displayname` 等元素，正则不能要求它们相邻。

**修法**：先按 `<D:response>(.*?)</D:response>` 切块，再在块内各自找。

## 二、ffmpeg / ffprobe

### 5. PSNR/SSIM 抓不到值

**症状**：跑完显示 NA。

**根因**：`-v error` 把 PSNR/SSIM 的 info 级摘要吞掉了。

**修法**：用 `-hide_banner`（info 级）+ `grep -oE "average:[0-9.]+"`。

### 6. volumedetect 同样被吞

**症状**：验证音频是否静音，无输出。

**根因**：同上，`volumedetect` 输出在 info 级。

**修法**：`-hide_banner` 不带 `-v error`。

### 7. float WAV 读不了

**症状**：Python `wave` 模块报 format 3 错误。

**根因**：`wave` 模块不支持 IEEE float。

**修法**：手动解析 RIFF。注意 `comp_full.wav` 的 `data` chunk 在偏移 92（前面有 LIST chunk），用 `np.fromfile(offset=...)` 切读最省内存。

### 8. HVCC 直接喂 ffmpeg 解不出帧

**症状**：全程 `PPS id out of range`，一帧都解不出。

**根因**：HVCC 用 4 字节长度前缀，ffmpeg 把 `00 00 00 1d` 当垃圾吞掉了。

**修法**：先转 Annex B（起始码 `00 00 00 01`）再喂。

### 9. 开头帧被自动丢弃

**症状**：成品比源少 6.5 秒。

**根因**：开头 379 帧没有参数集且缺所属 GOP 的 IDR（App 预解码过），RPS 报错被 ffmpeg 自动丢弃。

**修法**：从第一个 IDR 起；要补开头需重播前 10 秒抓首帧 IDR 再 splice。

## 三、shell

### 10. zsh 不做 SH_WORD_SPLIT

**症状**：`for f in $files` 只跑一次。

**根因**：zsh 默认不对未加引号的变量做词分割。

**修法**：`while read -r f; do ... done`。

### 11. WebDAV DELETE 全 000

**症状**：删文件返回 000，实际没删。

**根因**：`todel.txt` 里存的是路径不是完整 URL。

**修法**：拼完整 URL `http://<host>:<port>$path`。

### 12. 文件名直接写不匹配

**症状**：`ffmpeg -i "5.《女主》二.mp4"` 找不到文件。

**根因**：文件名里的字符被 shell 或脚本转义搞坏了。

**修法**：用 glob `5.*.mp4`。

## 四、注入 / 逆向

### 13. fishhook hook 不上

**症状**：符号明明存在，hook 后不触发。

**根因**：`AwemeJXCore` 符号表里大量 `radr://5614542` 形式的**假条目**，真实绑定在自研节 `__bd_la_sym_ptr`。

**修法**：按值扫描指针槽，别信符号名。

### 14. 注入后闪退

**症状**：App 一启动就崩。

**根因**：一开始以为补丁打错了。实测根因是**启动期 dyld API 竞争**——constructor 里调 dyld 相关 API 会和 dyld 自己抢锁。

**修法**：错峰下补丁 + SIGSEGV 保护 + 只过滤 app-bundle 内的槽。

### 15. hook 错了类

**症状**：日志 `[!] AVAudioEngine 无 installTapOnBus...`。

**根因**：`installTapOnBus:bufferSize:format:block:` 和 `removeTapOnBus:` 在新版 SDK 里从 `AVAudioEngine` **挪到了 `AVAudioNode`**。

**修法**：hook 前先用 `class_copyMethodList` 核实方法在哪个类上。

### 16. objc_msgSend 隐式声明报错

**症状**：编译报隐式声明。

**修法**：`#import <objc/message.h>`。

### 17. 中文 NSString 字面量搜不到

**症状**：在二进制里搜中文字符串搜不到。

**根因**：Apple 平台含非 ASCII 的 NSString 字面量以 **UTF-16 存 `__ustring`**（不是 `__cstring` 的 UTF-8）。

**修法**：搜 utf-16-le。另：新版 clang 用 `__init_offsets` 替代 `__mod_init_func` 注册 constructor。

## 五、方法论

### 18. 用熵值判断加密（最贵的一个坑）

完整复盘见 [03-加密研究完整复盘](03-加密研究完整复盘.md#3-误判的根因)。

**一句话**：压缩视频熵本来就是 8.0。要判加密，**解 NAL 结构**。

### 19. 方向搞反了却越修越糟

**症状**：音画不同步，修了几轮越来越糟。

**根因**：一直假设"音频滞后"，实际是"音频超前"。纯推理判断谁超前谁滞后，很容易搞反。

**修法**：用**客观锚点**互相关，别靠推理——
crop 嘴部区域算帧差 vs 音频能量，互相关扫滞后 L；再用字幕切换帧（字幕切换必落说话边界）交叉验证。**先验证多个候选的相对偏移是否与已知样本偏移自洽，再信绝对值。**

### 20. 样本级偏移不能四舍五入

**症状**：偏移差 21 个样本，相关系数从 0.999 跌到 -0.32。

**根因**：语音相关峰极窄。

**修法**：一切偏移量必须样本级精确，禁四舍五入到毫秒。

### 21. 前台 agent 跑长任务

**症状**：用户体感"卡死了"。

**根因**：10–40 分钟无反馈的前台任务。

**修法**：长任务一律 `run_in_background`，任务拆小，先交关键修复再补分析。

### 22. PSNR 饱和导致指标失效

**症状**：CRF 从 18 调到 30，PSNR 几乎不动（34.62 → 34.46 dB）。

**根因**：原片本身已是压缩流，重编差异被原片量化噪声主导，指标失灵。

**修法**：用**近无损参考法**——先拿 crf 8 x265 做 REF，分别测「原片 vs REF」和「重编 vs REF」，看谁更接近真源。
